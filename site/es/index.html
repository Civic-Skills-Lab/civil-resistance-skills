Civic Research Atlas

Habilidades de nivel investigativo para estudiar y simular métodos de resistencia civil.

Un registro estructurado para estudiar, simular y preparar con cuidado métodos de resistencia civil con agentes de IA. Construido a partir de taxonomías públicas, registros con fuentes y diseño de habilidades con control de riesgo.

Esta es infraestructura para investigación, educación, simulación y planificación. No es un organizador de campañas, y los métodos de alto riesgo se mantienen para análisis, no para guía operativa. Consulta la política de seguridad del repositorio antes de usarlo.

Por qué existe

Los métodos de resistencia civil suelen publicarse como taxonomías en prosa. Los agentes necesitan algo más explícito: procedencia, límites de riesgo, disponibilidad operativa, referencias y criterios de finalización.

Base de fuentes

El registro cruza el universo táctico Beer/NVI/ICNC con la taxonomía de métodos de Sharp. Las fuentes primarias identifican el método; las fuentes secundarias de formación informan patrones de preparación low-risk.

Transformación con control de riesgo

Los métodos low-risk pueden convertirse en habilidades operativas con planificación, investigación, revisión y debrief. Los métodos high-risk siguen siendo descriptivos para educación, análisis y simulación hasta una revisión explícita.

Para quién

Investigadores, educadores cívicos, constructores de agentes, diseñadores de simulación, analistas de apoyo a movimientos y practicantes que necesitan aprendizaje estructurado, no consignas.

Ruta hacia la simulación

Las habilidades se forman como artefactos estructurados: fases, outputs, controles, flags de riesgo y veredictos de preparación. Eso las hace útiles para futuros agentes de sandbox y juego.

Superficies de instalación

Las habilidades canónicas viven en este repositorio. Claude Code y Codex usan superficies de marketplace separadas para que cada agente descubra habilidades en su propio formato nativo.

Claude Code

Añade el marketplace y después instala el plugin de comunicación.

Codex

Añade el marketplace de Codex y luego elige plugins desde la interfaz nativa.

Dominios

Seis dominios organizan los 347 métodos. Comunicación es el primer dominio activo; los demás siguen respaldados por el registro y marcados como próximamente hasta que se creen habilidades operativas.

Atlas de métodos

Las filas implementadas enlazan a los archivos canónicos de habilidades. Las filas próximamente son métodos indexados aún no convertidos en habilidades. Las filas high-risk son solo de análisis.
