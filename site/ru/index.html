Зачем это существует

Методы гражданского сопротивления обычно публикуются как прозаические таксономии. Агентам нужна более явная структура: происхождение, границы риска, операционная доступность, references и критерии завершения.

Источник метода

Реестр сопоставляет тактики Beer/NVI/ICNC с таксономией методов Sharp. Первичные источники задают идентичность метода; вторичные training sources помогают формировать low-risk подготовку.

Риск-гейтированный переход

Low-risk методы могут становиться операционными навыками с планированием, исследованием, review и debrief. High-risk методы остаются описательными для образования, анализа и симуляции до явного review.

Для кого

Для исследователей, civic educators, создателей агентов, дизайнеров симуляций, аналитиков поддержки движений и практиков, которым нужна структурированная учебная среда, а не лозунги.

Путь к симуляции

Навыки оформляются как структурированные артефакты: фазы, outputs, guards, risk flags и verdict готовности. Это делает их пригодными для будущих sandbox/game agents.

Поверхности установки

Канонические навыки живут в этом репозитории. Claude Code и Codex используют отдельные marketplace-поверхности, чтобы каждый агент находил навыки в своём нативном формате.

Claude Code

Добавьте marketplace, затем установите communication plugin.

Codex

Добавьте Codex marketplace, затем выберите плагины в нативном UI.

Домены

Шесть доменов организуют 347 методов. Коммуникация активна первой; остальные домены остаются registry-backed и помечены как coming soon, пока не будут написаны операционные навыки.

Атлас методов

Реализованные строки ведут к каноническим skill files. Coming soon строки - индексированные методы, ещё не превращённые в навыки. High-risk строки остаются analysis-only.
